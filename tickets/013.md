# 013 — Enlarge form controls and fix remote cursor visibility

Status: Implemented — awaiting confirmation on the actual Mac
Priority: P0
Depends on: 011, 012

## Scope

User feedback during the first successful Mac connection: fields were too small,
password visibility was missing, and the remote mouse pointer was invisible.

- Give connection fields explicit minimum widths/heights and add Show/Hide password buttons in both frontends.
- Request remote cursor shapes and validate dimensions, masks, and hotspots in the native adapter.
- Draw the cursor in egui and use a texture cursor in GTK; retain a local pointer until a valid remote shape arrives.
- Cover rich-cursor negotiation and mask/hotspot decoding with a protocol regression test.
- Build and install the updated binaries without interrupting the existing Mac session.

## Acceptance criteria

- [x] Both binaries build with larger controls and explicit password visibility.
- [x] Rich-cursor decoding regression passes and both frontends compile with cursor presentation.
- [x] A real local TigerVNC server supplies a valid 9×16 remote cursor through the core.
- [x] Updated builds installed and updated egui login window opened for the user.
- [ ] User confirms the new form controls and cursor work on the actual Mac.
