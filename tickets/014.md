# 014 — Shared terminal manager and connected graphical viewer

Status: Done — implemented and locally verified; actual Mac terminal workflow remains in the interactive validation matrix
Priority: P1
Depends on: 003, 004, 005, 011, 012

## Scope

- Make a shared Ratatui terminal interface the default in both binaries, with compact Omarchy palette styling and a persistent shortcut bar.
- Manage profiles, editing, transient authentication, password visibility, cancellation, and failures in the terminal.
- Open the graphical viewer only after the same core session connects and has a framebuffer; keep that session alive without reauthentication or credential IPC.
- Retarget session wakeups safely when attaching a viewer. Keep terminal restoration correct on errors and exit.
- Return to the terminal manager after viewer close, disconnect, or remote failure, supporting another connection in the same process.
- Retain the graphical connection manager with --gui.
- Update launcher entries to open the selected terminal and test both toolkit lifecycles independently.

## Acceptance criteria

- [x] Profile editing and persistence, password masking/reveal, connection failure, cancellation, and small terminal sizes are verified.
- [x] Terminal state is restored before/after graphical viewing and on errors.
- [x] A connected session retains its identity, framebuffer, and connection through the UI transition.
- [x] Both frontends connect to the local VNC server and return to the terminal; a second connection works.
- [x] GUI-only mode remains available and builds stay independent.
- [x] Updated builds, launcher entries, documentation, and checks are complete.

## Evidence

Workspace tests, Clippy, formatting, independent release builds, and installer tests pass.
Private PTY tests exercised failed and cancelled connections, two connect/view/return cycles,
terminal restoration, and terminal-free --gui operation for each frontend. The session
regression verifies identity and framebuffer preservation across callback retargeting.
The terminal layout was visually checked in Foot using synthetic profiles.
