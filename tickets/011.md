# 011 — Implement the egui/OpenGL frontend

Status: Implemented — remaining interactive checks tracked in docs/validation.md
Priority: P1
Depends on: 004, 005, 006, 007

## Scope

Use egui with eframe and its Glow/OpenGL renderer. Enable Wayland explicitly as needed by the selected versions; exclude GTK-pulling convenience dependencies. Upload validated core framebuffer data into textures; request repaint on changes and avoid idle busy loops. Handle texture size limits, resize, and GPU initialization failures gracefully. Apply the shared palette through egui styling.

- Implement saved-connections, first-run/edit forms, authentication, connecting/cancel, remote desktop, errors, disconnect, and manual reconnect views using shared core commands/state.
- Implement fit/1:1 display, aspect ratio, HiDPI, fullscreen, and a reliable local escape shortcut.
- Translate local keyboard/pointer/focus events into the neutral core input contract. Release tracked input on focus loss and intercept local shortcuts deliberately.
- Implement explicit text clipboard opt-in and remote cursor presentation without double drawing or synchronization loops.
- Keep local widget/window state here; keep connection policy and profiles in the core.
- Support keyboard-only navigation and profile selection from startup arguments without command-line credentials.
- Stop owned sessions on close and wake the UI safely when connection events arrive.

## Acceptance criteria

- [ ] This frontend builds and launches independently under Wayland/Hyprland.
- [ ] The complete saved-profile-to-remote-session workflow succeeds on the actual Mac mini.
- [ ] Scaling, fullscreen, keyboard/pointer, cursor, local escape, cancellation, and clipboard settings behave as specified.
- [ ] Slow/disconnected sessions leave the UI responsive; window close releases resources.
- [ ] UI consumes shared core behavior without reimplementing protocol, persistence, or session policy.
