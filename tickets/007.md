# 007 — Implement keyboard, pointer, cursor, and optional clipboard

Status: Implemented — remaining interactive checks tracked in docs/validation.md
Priority: P1
Depends on: 006

## Scope

Define toolkit-independent input events and protocol translation with predictable local control. Native event capture, clipboard access, and cursor presentation belong to tickets 011 and 012.
- Map normalized frontend pointer coordinates through scaling, letterboxing, scrolling, and HiDPI; handle buttons and scroll events.
- Define and verify Linux-to-Mac Command/Option/Control mapping, shortcuts, and the user's keyboard layout. Document unsupported layouts or IME behavior.
- Track pressed keys/buttons and release them on focus loss, disconnect, and fullscreen exit to avoid stuck modifiers.
- Reserve a reliable local escape shortcut; identify compositor-reserved shortcuts that cannot be forwarded under Wayland.
- Display the remote cursor without double drawing.
- Add explicit text clipboard opt-in when backend support is verified; avoid feedback loops and unnecessary clipboard access, cap transfer size, and stop synchronization when disconnected.

## Acceptance criteria

- [ ] Typing, modifiers, click/drag, scrolling, and local focus recovery work on the Mac.
- [ ] Coordinate transforms are tested across fit/1:1 modes and letterboxed/HiDPI views.
- [ ] Focus loss/disconnect cannot leave application-tracked keys or buttons pressed.
- [ ] Clipboard behavior matches the chosen setting and unsupported features are documented.

Implementation authorized by the user on 2026-10-18. See [validation results](../docs/validation.md) for completed checks and remaining work. The backend is LibVNCClient, selected to preserve the Mac’s Apple account authentication setup.
